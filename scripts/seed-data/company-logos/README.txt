Company logos, named after each company's slug (the last part of its web address),
e.g. matel-motion.png, emo-energy.svg, fitsol.png. SVG or a large transparent PNG.

Most are the official logos the team shared (Nov 2026), trimmed with a transparent
background. EMO, Protonas and CIMWare are still soft placeholders cropped from the Fund I
portfolio PDF.

To change a logo:
  - In the CMS: open the company → Basics → Logo, and upload the new file (best), or
  - Here: replace the file (same name) and run  npm run company:logos

The import replaces a logo only if it came from this folder; a logo uploaded by an
editor in the CMS is never overwritten.
